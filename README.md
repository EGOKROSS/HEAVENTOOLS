🌐 HEAVENTOOLS
A lightweight, cross-platform CLI tool built in Python for network diagnostics and web reconnaissance. It features a custom 3D ASCII terminal UI and a variety of useful web and IP utilities.

✨ FEATURES
IP & Network Tools: IP Lookup, Reverse DNS, Port Scanner, Ping, DNS Lookup.

Web Tools: Cookie Inspector, Robots.txt Scraper, Tech Stack Detector, HTTP Headers, Link Unshortener.

Utilities: Base64 Encoder/Decoder, Hash Generator, Password Generator, Subdomain Scanner.

💻 INSTALLATION (Windows - EXE)
For Windows users who do not have Python installed, you can download the compiled executable.

Download the HEAVENTOOLS.exe file directly from this repository.

Right-click the .exe and select "Run as Administrator" (Required for network tools like Port Scanner and Ping to function correctly).

🐧 INSTALLATION (Linux - Kali, Ubuntu, Debian)
Open your terminal and run the following commands:

Clone the repository:


git clone https://github.com/EGOKROSS/HEAVENTOOLS.git
Navigate into the folder:


cd HEAVENTOOLS
Install the required dependencies:


pip3 install -r requirements.txt
Run it:

python3 HEAVENTOOLS.py
