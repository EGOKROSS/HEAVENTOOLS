# 🌐 HEAVENTOOLS

A lightweight, cross-platform CLI tool built in Python for network diagnostics and web reconnaissance. It features a custom 3D ASCII terminal UI and a variety of useful web and IP utilities.

## ✨ FEATURES
* **IP & Network Tools:** IP Lookup, Reverse DNS, Port Scanner, Ping, DNS Lookup.
* **Web Tools:** Cookie Inspector, Robots.txt Scraper, Tech Stack Detector, HTTP Headers, Link Unshortener.
* **Utilities:** Base64 Encoder/Decoder, Hash Generator, Password Generator, Subdomain Scanner.

## 💻 INSTALLATION (Windows - EXE)
The compiled Windows executable is already included in the main branch of this repository.

1. Download the **`HEAVENTOOLS.exe`** file directly from this repository.
2. **Right-click** the `.exe` and select **"Run as Administrator"** (Required for network tools like Port Scanner and Ping to function correctly).
3. No Python installation or setup required.
